# Weline Localnet v0.2.1

## 简体中文

Weline Localnet v0.2.1 重点优化复杂内网中的发现速度、好友上线感知和好友状态一致性。

- 将同一设备在 mDNS、局域网信标和主动探测中出现的地址在 **75 ms** 内汇集，一次并发尝试多个连接候选，避免错误 TUN/虚拟网卡路径逐个阻塞。
- 优先使用已认证的真实局域网路径；TUN、VPN、VMware、Hyper-V、WSL 等地址仍作为回退，不会被简单排除。
- 在本机安全记住好友最近一次经过加密握手认证的私有内网地址，并每 **2 秒**快速探测；好友重新上线后无需等待完整扫描周期。
- 好友接受或拒绝结果写入 SQLite 持久队列，发送瞬间断线或应用重启后，会在下一次握手时自动补发。
- 一端已有好友而另一端再次申请时自动完成好友状态对账，不再重复弹出申请。
- 支持不同软件版本之间的基础发现和好友申请；不再因为界面中的数字版本不完全相同而禁用“添加好友”。
- 已是好友、已有已接受记录或申请正在处理中时，不再显示可重复点击的“添加好友”。

## English

Weline Localnet v0.2.1 focuses on faster discovery, prompt friend-presence updates, and reliable friendship convergence on complex LANs.

- Batches addresses learned through mDNS, LAN beacons, and active probes for **75 ms**, then dials multiple candidates concurrently instead of letting a poor TUN or virtual-adapter path block the next candidate.
- Prioritizes authenticated physical-LAN paths while retaining TUN, VPN, VMware, Hyper-V, and WSL addresses as fallbacks.
- Safely remembers a friend's last private LAN address after an authenticated encrypted handshake and probes remembered friends every **2 seconds**, avoiding the full-scan delay after they come back online.
- Persists friendship decisions in SQLite and automatically retries them on the next handshake after a disconnect or app restart.
- Automatically reconciles a new request from an existing friend without showing another approval prompt.
- Keeps base discovery and friend requests compatible across supported app versions and no longer disables Add Friend just because numeric versions differ.
- Never shows an actionable Add Friend button for an existing friend, an accepted relationship, or a request that is already pending.
