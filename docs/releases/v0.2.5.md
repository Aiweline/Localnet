# Weline Localnet v0.2.5

## 修复

- 修复好友设备改名后好友列表仍显示旧昵称的问题。
- 好友列表按唯一 `PeerId` 关联，并优先展示设备最新 hello 中的昵称；改名不会生成重复好友，也不会重新显示“添加好友”。
- 保留离线好友的本地昵称作为安全回退，设备重新上线后自动同步最新名称。

## Fixes

- Fixed stale friend names after a peer changes its device nickname.
- Friends remain keyed by the stable `PeerId`, while the latest authenticated peer presence supplies the displayed nickname.
- Offline friends retain their last known local name until the next hello updates it.
