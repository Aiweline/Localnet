# Weline Localnet v0.2.2

## 简体中文

Weline Localnet v0.2.2 修复好友关系已经在本地生效、界面却仍把对方显示为“附近用户”并提供重复添加按钮的问题。

- 已经存在好友关系时，再次点击“添加好友”会作为幂等成功处理，不再弹出“双方已经是好友”的错误提示，也不会发送重复申请。
- 收到好友申请接受事件后，界面立即更新好友数量和好友列表，并同步移除附近用户中的“添加好友”入口。
- 后台权威快照刷新仍会继续运行，用于恢复偶发丢失的界面事件。
- 不修改局域网发现协议、好友身份、数据库结构或文件传输协议，继续兼容受支持的 0.1.x 和 0.2.x 版本。

### 下载内容

- Windows x64 安装版与便携版
- macOS Universal DMG（Apple Silicon + Intel）
- Windows 与 macOS 的 SHA-256 校验文件

## English

Weline Localnet v0.2.2 fixes a friendship-state mismatch where an established friend could still appear under Nearby Users with an actionable Add Friend button.

- Repeating Add Friend for an existing relationship is now an idempotent success: no duplicate request is sent and no “already friends” error is shown.
- When a friend request is accepted, the UI immediately updates the friend count and friend list and removes the Add Friend action from Nearby Users.
- Authoritative background snapshot reconciliation remains in place to recover from an occasionally missed UI event.
- LAN discovery, peer identity, the database schema, and file-transfer protocols are unchanged, preserving compatibility with supported 0.1.x and 0.2.x releases.
