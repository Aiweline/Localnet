# Weline Localnet v0.2.3

## 简体中文

Weline Localnet v0.2.3 改进持续发现、好友身份、安装语言、系统通知和应用更新体验。好友关系始终绑定设备唯一 PeerId，修改昵称不会改变好友身份。

- 局域网发现会持续运行，找到或添加一个好友后仍会继续发现其他设备。
- “附近用户”新增真正的网络刷新按钮，会立即触发广播和主动探测；一次卡住的快照不会永久占用后续刷新。
- 好友只按经过认证的 PeerId 识别。设备改名不会改变好友关系，已添加设备不会再次显示“添加好友”。
- Windows NSIS 安装器在安装前提供 English、简体中文、Español、Français、Deutsch、Português (Brasil)、Русский、日本語、한국어、العربية，共十种语言选择。macOS 继续使用标准 Universal DMG 流程。
- 首次启动在系统权限尚未决定时主动申请一次通知权限；拒绝或权限接口异常后不会反复弹窗，设置页仍可手动重试。
- 标题旁直接显示当前版本号，设置页可手动检查更新。
- 应用从 `Aiweline/Localnet` 官方 GitHub Release 检查更高的稳定版本，只下载当前平台的精确安装包，并在打开前校验 GitHub 提供的 SHA-256 摘要。
- 更新检查和下载失败不会影响内网发现、聊天或文件传输；应用不会静默安装或绕过 Windows/macOS 的安全确认。

### 下载内容

- Windows x64 安装版与便携版
- macOS Universal DMG（Apple Silicon + Intel）
- Windows 与 macOS 的 SHA-256 校验文件

## English

Weline Localnet v0.2.3 improves continuous discovery, stable friend identity, installer language choice, system notifications, and application updates. Friend relationships remain bound to the device's unique PeerId, so renaming a device never changes its identity.

- LAN discovery keeps running after a device is found or added, so other devices remain discoverable.
- Nearby Users now has a real network refresh action that immediately triggers announcements and active probes. A stalled snapshot can no longer occupy every later refresh.
- Friendship is keyed only by the authenticated PeerId. Renaming either device does not change the relationship, and an accepted friend never reappears with Add Friend.
- The Windows NSIS installer offers ten language choices before installation. macOS keeps its standard Universal DMG flow.
- On first startup, the app requests notification permission once when the operating system has not decided yet. A denial or permission API failure is not repeatedly prompted; Settings remains the manual recovery path.
- The running version is shown beside the product title, and Settings includes a manual update check.
- The app checks only the official `Aiweline/Localnet` GitHub Release, accepts only a newer stable version and the exact platform package, and verifies GitHub's SHA-256 digest before the package can be opened.
- Update failures never block LAN discovery, messaging, or file transfer. Installation remains user-confirmed and does not bypass Windows or macOS security prompts.

- macOS Universal DMG (Apple Silicon + Intel)
- SHA-256 checksum files for Windows and macOS
