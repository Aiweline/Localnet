# Weline Localnet v0.2.4

## 简体中文

Weline Localnet v0.2.4 完成十语言客户端，并让已完成传输的图片和文件可以直接从聊天记录管理。

- 应用界面完整支持简体中文、English、Español、Français、Deutsch、Português (Brasil)、Русский、日本語、한국어和العربية；可跟随系统，也可在首次设置或“设置”中即时切换并持久保存。
- Windows NSIS 安装器在全新安装和升级时都会显示十语言选择，不再因旧版本保存过安装语言而跳过；安装时选择的语言会传递给应用首次启动。
- macOS Universal 应用为“本地网络”系统授权提供十种本地化说明，系统语言不在支持列表时使用英文回退。
- 已完成传输的图片和文件在聊天记录中提供“打开”“另存为”“在文件夹中显示”三个操作。
- “另存为”由 Rust 后端按消息唯一 ID 读取数据库中的真实文件位置；文本消息、未完成传输或缺失文件不能被当作任意路径复制入口。
- 阿拉伯语使用从右到左布局；昵称、聊天内容和文件名保持用户原文，不被翻译。
- 本次没有修改 PeerId、好友关系、发现协议、聊天协议或大文件续传协议；0.1.x 与 0.2.x 的既有兼容关系保持不变。

## English

Weline Localnet v0.2.4 completes the ten-language client and adds direct file management to completed image and file records in chat.

- The complete interface supports Simplified Chinese, English, Spanish, French, German, Brazilian Portuguese, Russian, Japanese, Korean, and Arabic. It can follow the operating system or switch immediately from onboarding or Settings, with the preference persisted.
- The Windows NSIS installer shows its ten-language selector for both new installations and upgrades instead of skipping it because an older installer language was remembered. The chosen language is handed to the app on first launch.
- The universal macOS app includes ten localized Local Network permission descriptions, with English as the fallback for unsupported system languages.
- Completed images and files in chat expose Open, Save as, and Show in folder actions.
- Save as resolves the authoritative local file from the message's unique ID in the Rust backend. Text messages, unfinished transfers, and missing files cannot be used as arbitrary path-copy entry points.
- Arabic uses a right-to-left layout. Nicknames, message content, and filenames always remain user-authored text and are never translated.
- PeerId, friendship, discovery, messaging, and resumable-transfer protocols are unchanged. Existing 0.1.x and 0.2.x compatibility remains intact.
