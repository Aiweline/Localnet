# Weline Localnet v0.2.0

## 简体中文

Weline Localnet v0.2.0 为已升级设备带来可恢复的大文件直传能力。

- 默认支持单个文件最高 **100 GiB**；v2 传输协议不再有 2 GiB 硬限制。
- v2 使用 **4 MiB** 分块，并对每个分块进行 SHA-256 完整性校验；已确认的传输状态可用于续传。
- 接收文件和恢复传输前，会检查可用磁盘空间、目标目录是否可写且可用，以及 FAT32/MSDOS 文件系统的单文件大小限制。
- 可恢复的网络中断或应用重启后，传输会在条件恢复时自动继续，而不是从头开始。
- 续传 v2 需要双方都使用 v0.2.0。0.1.x 设备仍通过旧版 v1 保持兼容，但单个文件最大为 2 GiB。

## English

Weline Localnet v0.2.0 brings resumable large-file transfers to upgraded devices.

- By default, a single file can be up to **100 GiB**; the v2 transfer protocol no longer has a 2 GiB hard limit.
- v2 uses **4 MiB** chunks with SHA-256 integrity validation for every chunk, and keeps confirmed transfer state for resuming.
- Before accepting or resuming a transfer, Localnet checks free disk space, destination writability and availability, and single-file limits on FAT32/MSDOS file systems.
- After recoverable network loss or an app restart, a transfer automatically continues when conditions recover instead of starting over.
- Resumable v2 requires v0.2.0 on both peers. Version 0.1.x peers remain supported through legacy v1, with its existing 2 GiB per-file maximum.
