# Weline Localnet v0.2.6

## 修复

- 修复好友改名后昵称已同步、在线状态却仍显示离线的问题。
- 收到设备 hello 时，按唯一 `PeerId` 同步好友昵称和在线状态，并立即更新界面。
- 使用 libp2p 连接事件提供的剩余连接数维护在线状态，避免交错连接关闭误把仍在线好友标记为离线。

## Fixes

- Fixed the case where a renamed friend showed the new nickname but remained offline.
- Peer hello events now update the matching friend’s nickname and online state immediately by stable `PeerId`.
- Connection state now uses libp2p’s remaining-connection count to avoid false offline transitions during overlapping reconnects.
