# Weline Localnet v0.2.7

## 修复

- 应用的 TCP 监听端口就绪后，立即启动局域网广播、普通主动扫描和已认证好友地址优先探测，不再等待下一次周期定时器。
- 修改昵称后，立即向当前已连接设备发送新的认证 Hello，使对方在数秒内同步昵称和在线状态，不再等待约 120 秒的空闲连接重建。
- 保留 mDNS、兼容 mDNS、局域网信标、TUN/代理回退和不同受支持版本之间的基础发现兼容性。

## Fixes

- LAN broadcast, generic active scanning, and priority probing of authenticated friend addresses now start as soon as the TCP listener is ready instead of waiting for the next periodic tick.
- Nickname changes now send a fresh authenticated Hello to connected peers immediately, so nickname and online state converge within seconds instead of waiting for the roughly 120-second idle reconnect.
- mDNS, compatibility mDNS, LAN beacons, TUN/proxy fallbacks, and base discovery compatibility across supported versions remain enabled.
