# Weline Localnet v0.2.4 Localization and File Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a Windows installer that always asks for one of ten languages, run the complete client UI in that language, and add Save As plus file-location actions to completed attachment records.

**Architecture:** The existing ten-language design remains the product contract, with a typed React catalog/provider and a device-local SQLite language preference. The NSIS hook always displays the language selector and writes the selected canonical locale to a one-shot app-data marker that Rust validates and imports before bootstrap. Attachment operations use message IDs at the Tauri trust boundary so the renderer cannot copy arbitrary local files.

**Tech Stack:** React 19, TypeScript 5.9, Tauri 2, Rust 2024, SQLite, NSIS, Node test runner.

**Spec:** `docs/superpowers/specs/2026-08-23-weline-chat-i18n-design.md`, adapted to product name Weline Localnet and release 0.2.4; the explicit current requirements override the old 0.1.4 version references.

## Global Constraints

- Support exactly `zh-CN`, `en-US`, `es-ES`, `fr-FR`, `de-DE`, `pt-BR`, `ru-RU`, `ja-JP`, `ko-KR`, and `ar-SA`.
- Windows interactive installation must always display the language selector, even after an earlier Weline Localnet installation saved a language.
- The installer selection must become the client language on the next launch; portable and macOS builds fall back to persisted preference and OS language matching.
- Locale choice is device-local and must not alter PeerId, discovery, friendship, chat, or transfer wire formats.
- Save As and reveal actions are available only for delivered image/file messages with a backend-owned recorded source path.
- No GUI or installer is launched on this development host.
- All user-visible code changes require version 0.2.4 before merge and release.
