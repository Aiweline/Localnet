# Weline Localnet v0.2.3 Client Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Weline Localnet v0.2.3 with a visible ten-language Windows installer selector, authoritative friend rendering, one-time startup notification permission, an always-visible app version, and a safe GitHub release update download flow.

**Architecture:** Keep SQLite plus authenticated `PeerId` as the only friendship authority and keep discovery protocol-compatible with existing peers. Put GitHub release parsing and notification startup policy in small testable TypeScript modules; keep installer/package validation and downloaded installer verification in Rust so the renderer never opens an arbitrary URL or path. The update flow checks GitHub without blocking startup, downloads only the exact platform asset from the fixed repository, verifies its GitHub SHA-256 digest, then asks the operating system to open the verified installer.

**Tech Stack:** Tauri 2, React 19, TypeScript 5.9, Rust 2024, Tokio, Reqwest with rustls, SHA-256, NSIS, GitHub Releases.

**Spec:** `docs/superpowers/specs/2026-08-25-v0.2.3-client-experience-design.md`

## Global Constraints

- Release version is exactly `0.2.3` in `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.lock`.
- The Windows NSIS selector exposes exactly English, Simplified Chinese, Spanish, French, German, Brazilian Portuguese, Russian, Japanese, Korean, and Arabic.
- macOS keeps the normal DMG installation flow because DMG has no installer wizard language page.
- Friendship is determined only from the authenticated peer ID and the persisted SQLite friend record; nickname, IP address, and MAC address are never used as identity.
- The app automatically asks for notification permission only once when the operating system reports `default`; an explicit denial is not repeatedly prompted.
- Update checks use only `https://api.github.com/repos/Aiweline/Localnet/releases/latest` and accept only stable SemVer releases newer than the running application.
- Windows accepts only `Weline_Localnet_<version>_x64-setup.exe`; macOS accepts only `Weline_Localnet_<version>_universal.dmg`.
- A downloaded update is never opened until its byte count and GitHub `sha256:` digest match exactly.
- Updating is user-triggered and does not silently install or restart the application.
- Existing five-asset immutable GitHub release policy remains unchanged.
- Do not launch the packaged GUI on the development machine; previous local launches caused repeated operating-system authorization prompts.

- [ ] **Step 4: Implement strict request validation and verified streaming**

`validate_update_request` must enforce stable SemVer, current platform filename, exact HTTPS GitHub path, a lowercase 64-character SHA-256 value without the `sha256:` prefix, and `1..=536_870_912` bytes. `persist_verified_update_stream` must:

1. create a unique `create_new` partial in `<cache>/updates`;
2. reject a stream as soon as downloaded bytes exceed `request.size`;
3. emit progress after each chunk;
4. flush and `sync_all` the partial;
5. require exact byte count and digest;
6. rename to the exact asset filename only after verification;
7. delete the partial on every ordinary error path.

- [ ] **Step 5: Implement the production commands**

`download_update` must construct a Reqwest client with a connect timeout and fixed `User-Agent: Weline-Localnet/<running-version>`, require a successful response, reject contradictory `Content-Length`, and pass the response byte stream to the verified writer. It returns an already verified cached package without downloading again only when the cached file independently matches size and digest.

`open_downloaded_update` must revalidate the request, reopen the exact cached package, recompute its size and SHA-256, then call the Tauri opener from Rust. It must never accept an arbitrary renderer-supplied local path.
