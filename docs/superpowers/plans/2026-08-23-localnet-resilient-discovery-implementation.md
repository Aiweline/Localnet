# Localnet Resilient Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Parallel subagents are disabled for this repository session.

**Goal:** Make Localnet 0.1.1 automatically discover same-LAN peers with Windows/macOS proxy or TUN mode enabled.

**Architecture:** Add a bounded UDP broadcast discovery service beside libp2p mDNS. Both sources feed authenticated libp2p dialing; platform bundle metadata and the Windows installer provide the OS permissions necessary for inbound LAN traffic.

**Tech Stack:** Rust 1.85+, Tokio, rust-libp2p 0.56, socket2, if-addrs, Tauri 2, NSIS, macOS Info.plist, React/TypeScript.

**Spec:** `docs/superpowers/specs/2026-08-23-localnet-resilient-discovery-design.md`

## Global Constraints

- Keep transfers serverless and inside the LAN.
- A UDP beacon is an untrusted dial hint; only Noise plus Peer ID authenticates a peer.
- Do not add a cloud rendezvous service, subnet-wide host sweep, or MAC-address identity.
- Do not add persistent unit/E2E test files; use temporary diagnostics plus build and real-process acceptance.
- Do not modify unrelated UI or transfer behavior.
